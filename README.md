# MelodyLab v5.270 Doppler Core Style

สร้างหน้า Doppler ใหม่ให้ไปในแนวเดียวกับหัวข้อก่อนหน้า:
- ใช้โครงหน้า visualizerTemplatePage / rebuiltTopicPage แบบเดียวกับหัวข้อพื้นฐาน
- ใช้ canvas vector แทน sprite ขนาดใหญ่ เพื่อให้รถ คน และหน้าคลื่นสมดุลกับภาพจำลอง
- แสดงหน้าคลื่นเป็นวงกลมจากตำแหน่งเก่าของแหล่งกำเนิด เพื่อเห็นการบีบด้านหน้าและยืดด้านหลัง
- ใช้สูตรแหล่งกำเนิดเคลื่อนที่ ผู้ฟังอยู่นิ่ง:
  - เข้าใกล้: f′ = f v / (v − v_s)
  - ออกห่าง: f′ = f v / (v + v_s)

- อัปเดต cache เป็น v5.270
